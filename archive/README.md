# Earlier standalone tool

[star-wars-dice-roller.html](star-wars-dice-roller.html) preserves the repository's original unrelated browser dice page byte for byte. It is not connected to Iron Engine, does not save this campaign, and supplies none of its outcome rules.

The active entry point is [the repository README](../README.md). Original writing references and the supplied Eddard sheet remain in their designated source-input folders. Superseded blank character preparation and obsolete build-blocker notes were removed from the current tree; the prior Git commit retains them.
