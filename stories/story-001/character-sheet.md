# Character-Specific Adjudication

When resolving an uncertain action:

1. Use the most relevant established Sub-skill or Specialty.
2. Use the Domain Rating only for genuinely broad tasks or where no narrower established ability applies.
3. Use a Derived Rating only when the background genuinely supports the inference.
4. Separately consider attributes, equipment, overall Condition, its tags and concrete effects, wounds, fatigue, numbers, position, information, preparation, opposition, and terrain. Do not count the same impairment twice.
5. Aptitude affects development, not instant performance.
6. Do not count the same advantage twice.

Routine feasible actions succeed directly. Impossible actions need no check. Consequential uncertainty is resolved from the established circumstances, with the decisive cause stated briefly.
